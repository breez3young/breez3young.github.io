# LIBERO-Plus clips

These seven clips are representative successful episodes generated with the LIBERO-Plus harness using the Pretrained Predictor V-JEPA 2.1 ViT-L policy checkpoint. Each clip selects one task from one perturbation category and is recorded with the OSMesa renderer, seed 7, and one simulator client. The videos are native 256x256 agent-view rollouts; the JPEG posters are the first native rollout frames. They are qualitative examples; the aggregate results are reported in the paper and are not estimated from these seven episodes.
