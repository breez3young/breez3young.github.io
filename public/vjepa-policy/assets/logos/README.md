# Affiliation marks

The author order and numbered affiliation mapping follow the paper's `preprint.tex`. The header uses six standalone circular seals and the original Gamma Robotics wordmark. Institution names remain available in image alternative text and hover titles. The page preserves the artwork's colors and proportions.

| Asset | Source |
| --- | --- |
| `tsinghua-seal.svg` | Seal-only view of the existing `tsinghua.svg`: the SVG viewBox is limited to the original seal; its paths and colors are unchanged |
| `sjtu.png`, `fudan.svg`, `ustc.svg`, `washu.jpg` | Existing project assets, originally sourced from Wikimedia Commons / Wikipedia as recorded in the prior version of this file |
| `teleai.png` | Author-provided original from the paper's `figures/teleai.png`, copied unchanged |
| `gamma_robotics.png` | Author-provided original from the paper's `figures/gamma_robotics.png`, copied unchanged |

The superscript affiliation numbers follow the manuscript and are not part of the logos. The earlier wordmark assets are retained but are not displayed in the header. The unused `washu-wordmark.png` was obtained from [WashU's official artwork](https://washu.edu/app/uploads/2024/07/WashU-RGB_web.png).
